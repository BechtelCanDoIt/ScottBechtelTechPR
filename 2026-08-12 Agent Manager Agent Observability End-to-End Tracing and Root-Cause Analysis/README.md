# Agent Manager: Agent Observability: End-to-End Tracing and Root-Cause Analysis
**Date:** August 12, 2026  **Product:** [WSO2 Agent Manager](https://wso2.github.io/agent-manager/docs/latest/get-started/quick-start/)

## Business Problem
Enterprises running production agents built on LangChain, LangGraph, or CrewAI lose visibility the moment something goes wrong. A customer-facing agent quotes the wrong price or takes an unexpected action, and engineers are left grepping logs across a dozen services trying to reconstruct what the agent actually decided, which tool it called, and why. Without a single trace to follow, root-causing a bad agent decision can eat an entire afternoon.

## How WSO2 Solves This
WSO2 Agent Manager — an Apache 2.0 open-source project built on OpenChoreo — applies OpenTelemetry-based, zero-code instrumentation to Python agent frameworks (LangChain, LangGraph, CrewAI, LlamaIndex, and OpenAI-direct), capturing every LLM call and tool invocation as a structured trace with no app code changes: a Kubernetes init container copies the instrumentation package onto the app's PYTHONPATH. Engineers can open a single request end-to-end and replay the exact sequence of reasoning and tool calls. A built-in evaluation framework — 20+ built-in evaluators plus custom rubrics — scores each trace on a schedule (picked up within 60 seconds), and those scores and trends are reviewed in the console. It's the same visibility APM tools gave teams over microservices, now applied to autonomous agents.

## Patterns Used
- OpenTelemetry Distributed Tracing
- Zero-Code Instrumentation (Python)
- Scheduled Evaluation Scoring
